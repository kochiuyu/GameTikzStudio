TikZ Package Guide

All code utilizes standard TikZ matrix library (\usetikzlibrary{matrix}). No custom non-standard packages required.

\usepackage{tikz}
\usetikzlibrary{matrix, calc, positioning}

📖 Understanding the TikZ Code

  • \matrix (M) [matrix of nodes]: Creates an addressable grid where cell at row $r$, col $c$ is named (M-r-c).
  • column 1/.style: Styles Player 1's action names along the left edge.
  • row 1/.style: Styles Player 2's action names along the top edge.
  • \underline{u_1}: LaTeX underline denoting Player 1's best response to that column.
  • nebg / neborder: Highlights pure Nash Equilibria with mutual best responses.

Strategic Form & Payoff Matrix 101

Everything you need to know to read and build bimatrix games

1. How to Read Any Cell $(u_1, u_2)$

In a strategic game matrix, two players pick actions simultaneously:

  • Player 1 (Row Player): Selects which row is played. Their payoff is ALWAYS the first number ($u_1$).
  • Player 2 (Column Player): Selects which column is played. Their payoff is ALWAYS the second number ($u_2$).

2. The 30-Second Underline Method for Pure Nash Equilibria

How to find the Nash equilibria of any matrix in seconds:

  1. Look down each column one by one. Find Player 1's highest payoff (the first number in each cell) and underline it.
  2. Look across each row one by one. Find Player 2's highest payoff (the second number in each cell) and underline it.
  3. Any cell where both numbers are underlined is a Pure Strategy Nash Equilibrium ($\text{NE}^\star$)! The app automatically highlights these in emerald green.

3. What is a Dominant Strategy?

A strategy is strictly dominant if it gives a player a strictly higher payoff than all their other strategies, no matter what choice the opponent makes. (For example, in the Prisoner's Dilemma, "Defect" is a dominant strategy for both players).

4. What is IESDS (Iterated Elimination)?

IESDS stands for Iterated Elimination of Strictly Dominated Strategies. If a row or column is always worse than another option, rational players will never play it. In this studio, click the Dominate button next to any strategy to strike it through with a red line.
