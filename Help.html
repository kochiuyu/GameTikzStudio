🎓 Game Theory 101: Visual Guide for Beginners

Beginner Primer

Welcome to Game Theory! Whether you are taking your first economics, political science, or computer science class, this visual guide explains what every symbol, line, and number means.

🌳 1. How to Read an Extensive-Form Game Tree

A game tree illustrates sequential decisions over time. Think of it as a flowchart of choices:

● Decision Node (Root & Intermediate) Marks whose turn it is to act (e.g., Player 1 or Firm A). The branch lines emerging from this node are the available actions (e.g., "Enter" or "Stay Out").
○ Nature / Chance Node An external random event (coin flip, weather, economic climate). The branches represent probabilities that must sum to 1 (e.g., $p$ and $1-p$).
● Terminal Payoff $(u_1, u_2)$ The game concludes here. Crucial rule: The first number is Player 1's payoff; the second number is Player 2's payoff.
- - - Dashed Arc (Information Set) Connects decision nodes when a player must move without knowing which node was reached (e.g., Player 2 moves without seeing Player 1's action).

📊 2. How to Read a Payoff Matrix & The 30-Second Underline Method

A payoff matrix represents simultaneous games where both players decide without knowing each other's choice.

The 3-Step Underline Method for finding Pure Nash Equilibria:
  1. Check Row Player's Best Responses: Look at each column individually. Compare Player 1's payoffs (the 1st number in each cell) and underline the highest one ($\underline{u_1}$).
  2. Check Column Player's Best Responses: Look at each row individually. Compare Player 2's payoffs (the 2nd number in each cell) and underline the highest one ($\underline{u_2}$).
  3. Find Mutual Best Responses: Any cell where both numbers are underlined $(\underline{u_1}, \underline{u_2})$ is a Pure Strategy Nash Equilibrium ($\text{NE}^\star$)!

🎯 3. How Backward Induction Works on Game Trees

To solve sequential games, start at the end of the tree and reason backwards:

Step 1: Look at final decision nodes
Examine the last player's choices and select the branch that yields their highest individual payoff.
Step 2: Anticipate rational moves
The earlier player knows what the later player will do, so they choose the action that maximizes their own expected payoff.
Step 3: Highlight the SPNE path
Highlight the resulting branches in bold red in our Extensive-Form Studio to show the Subgame Perfect Nash Equilibrium.

💡 Frequently Asked Questions for New Learners

Do I need to know LaTeX syntax to use these studios?
No! You can type ordinary labels (e.g. Enter, Stay Out, Cooperate, (3, 1)). The tool formats everything into clean, standard TikZ code automatically.
How do I export my diagram into Microsoft Word or Google Slides?
Click Export PNG or Export SVG on the diagram toolbar. You will get a crisp, transparent vector or high-DPI image ready to drag directly into documents or slides.
How do I use this with Overleaf or my LaTeX research paper?
Click Open in Overleaf to instantly compile a complete standalone document in Overleaf, or click Copy TikZ Code to paste just the \begin{tikzpicture} ... \end{tikzpicture} snippet into your existing paper.

Architecture & Core Pillars

Pillars

Game Theory TikZ Studio is engineered specifically for economic theory, political science, and mathematical games. It provides dedicated tools for the three standard representations of strategic interaction:

🌳 Extensive-Form Studio

Sequential game trees, chance/nature nodes, imperfect information sets, and backward induction solution paths.

📊 Strategic-Form Studio

$2\times 2, 2\times 3, 3\times 3, N\times M$ bimatrix games with best-response underlines, Nash highlights, and IESDS.

⏱️ Game Stages & Timing

Sequence of play timelines ($t=0, 1, 2\dots$), active player mover badges, information states, and phase brackets.

1. Extensive-Form Game Tree Studio

GameTree.html

The Extensive-Form Studio models sequential decision problems, games with imperfect information, and games against Nature.

Node Hierarchy & Types
  • Player Decision Nodes: Solid filled circles labeled with the active player's name (e.g., Player 1, Firm 2).
  • Nature / Chance Nodes: Solid open circles representing random external events with probability branch labels (e.g., $p, 1-p$).
  • Terminal Nodes: Solid dots terminating a branch, formatted with a payoff vector tuple: $(u_1, u_2, \dots, u_n)$.
Information Sets (Simultaneous Moves)

When a player cannot observe which decision node was reached, select the nodes and click Create Information Set. The tool generates standard dashed TikZ curves connecting the nodes with player label identification.

Backward Induction & SPNE Highlighting

Mark branches on the Subgame Perfect Nash Equilibrium (SPNE) path as active. The generator formats them with bold colored lines and equilibrium arrows to emphasize the optimal decision path.

2. Strategic-Form Payoff Matrix Studio

PayoffMatrix.html

The Strategic-Form Studio builds clean bimatrix normal-form games using standard TikZ matrix of nodes.

Best-Response Underlining

Toggle auto best-response calculation or click individual payoffs. In LaTeX, Player 1 best-responses format as \underline{u_1} and Player 2 as \underline{u_2}.

Nash Equilibrium Highlights

Cells where both payoffs are mutual best responses automatically highlight in emerald green with a [fill=emerald!15] TikZ node style and a badge indicating Pure Strategy Nash Equilibria.

IESDS Domination Strike-Outs

Mark strictly dominated strategies for elimination. TikZ draws horizontal or vertical strike-through red lines (\draw[thick, red]) through the dominated rows or columns.

Classic Matrix Presets Included:

Prisoner's Dilemma Battle of the Sexes Matching Pennies Stag Hunt Hawk-Dove / Chicken Rock-Paper-Scissors Cournot 3x3 Discretized

3. Game Stages & Timing Studio

GameTiming.html

The Game Stages Studio visualizes the timing of the game for dynamic microeconomic and contract theory papers.

Timing Components & Syntax
  • Horizontal Time Axis: Directed line with ticks at discrete time periods: $t = 0, 1, 2, \dots$
  • Active Mover Badges: Identifies which player acts at each stage (e.g., Nature, Principal, Agent, Sender, Receiver).
  • Action Sets & Signals: Mathematical descriptions of chosen contracts $w(y)$, signal levels $e$, or price quotes $p$.
  • Information & Beliefs: Notes whether choices are public or private, and denotes Bayesian posterior updates $\mu(\theta \mid e)$.
  • Phase Brackets: TikZ decorations.pathreplacing curly braces grouping multiple stages into contractual phases.

4. LaTeX & Overleaf Integration Guide

Compilation

All code generated by Game Theory TikZ Studio is self-contained and compiles with standard LaTeX engines (pdfLaTeX, XeLaTeX, LuaLaTeX).

Recommended LaTeX Document Preamble
\documentclass[border=8pt]{standalone}
\usepackage{tikz}
\usepackage{amsmath, amssymb}

% Essential TikZ libraries used by the studios:
\usetikzlibrary{calc}                     % Coordinate mathematics
\usetikzlibrary{matrix}                   % Bimatrix normal-form grids
\usetikzlibrary{positioning}              % Relative node placement
\usetikzlibrary{decorations.pathreplacing}% Curly braces for timing phases

\begin{document}
  % Paste your generated \begin{tikzpicture} ... \end{tikzpicture} here
\end{document}
1-Click Overleaf Launch

Clicking Open in Overleaf submits the full standalone document directly to Overleaf via their official API, immediately creating a live compiling project in a new browser tab.

Snippet vs Standalone

Use TikZ Snippet if inserting a figure into an existing paper (\begin{figure}\centering ... \end{figure}). Use Full Document if compiling a dedicated standalone vector image.
