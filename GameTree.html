              📖 Understanding Extensive-Form TikZ Syntax
            

            
    
              
  • \node[decision] (n_id) at (x, y) {$P$};: Creates a solid circular decision node for player $P$.
    • 
              
  • \node[chance] (n_id) at (x, y) {$\mathcal{N}$};: Creates a chance node representing Nature / random draws.
    • 
              
  • \draw[edge] (parent) -- (child) node[midway, ...] {Action};: Draws an action branch with label and probability.
    • 
              
  • \draw[infoset] (nodeA) to[bend left] (nodeB);: Dashed arc grouping unobserved nodes into an information set.
    • 
              
  • \draw[equilibrium, line width=1.5pt]: Highlights the backward-induction Subgame Perfect Nash Equilibrium path.

Extensive Form & Game Trees 101

          
A simple breakdown of sequential game modeling

        

        
      

      

        

          

            1. What is an Extensive Form Game?
          

          

            While a matrix represents games where moves happen at the exact same time, a Game Tree models games where players move in sequence over time (like chess, bargaining rounds, market entry decisions, or multi-stage negotiations).
          

        


        

          

            2. The 3 Core Node Types
          

          
    
            
  • Decision Node (Solid Dot): Represents a specific player's turn to choose an action.
    • 
            
  • Chance / Nature Node (Open Circle): Represents an exogenous random event (e.g. coin flip, weather, or whether an applicant is high vs. low ability).
    • 
            
  • Terminal Node (Square / Dot with Payoffs): The endpoint of the game where no further actions are taken. Displays the final utility vector $(u_1, u_2, \dots, u_n)$.
    • 
          

        


        

          

            3. How Backward Induction Finds the Solution
          

          

            To solve any sequential game without imperfect information:
          

          
    
            
  1. Start at the very bottom of the tree (the final decision nodes before terminal payoffs).
    2. 
            
  2. Determine which branch gives the acting player the highest payoff. Mark this choice.
    3. 
            
  3. Work backward toward the root node, assuming players anticipate future responses.
    4. 
            
  4. The resulting highlighted path is the Subgame Perfect Nash Equilibrium (SPNE). Check the "Equilibrium / Subgame Perfect Path" box in this studio to render it in bold red!
    5. 
          

        


        

          

            4. What is an Information Set?
          

          

            A dashed arc connecting multiple nodes indicates an Information Set. This means the player knows it is their turn, but does NOT know which of the connected nodes they are actually at (e.g., in simultaneous moves or when the opponent's previous move is concealed).
